# Dimensional Architect - Web Edition

A browser-based HTML5 port of the turn-based resource management and civilization-building game originally written in Python.

## Overview

This web version faithfully ports the core gameplay mechanics from the Python version, providing an accessible browser-based experience with a clean, modern interface.

## How to Play

1. **Open the Game**: Simply open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).

2. **Basic Gameplay Loop**:
   - **Gather Resources**: Click "🌾 Gather Resources" to manually collect Light, Water, Energy, and Food
   - **Build Structures**: Click "🏗️ Build Structure" to construct buildings that enhance resource generation
   - **Upgrade Population**: Increase your civilization's capacity to support more citizens
   - **Next Turn**: Click "⏭️ Next Turn" to advance time, triggering automatic resource generation, population growth, and random events

3. **Resources**: Manage seven key resources:
   - ✨ **Light**: Primary resource for most buildings and upgrades
   - 💧 **Water**: Essential for survival and growth
   - 🌍 **Land**: Required for larger buildings (generated by Land Formation)
   - ⚡ **Energy**: Powers most activities and buildings
   - 🔩 **Metal**: Needed for advanced structures
   - 🍖 **Food**: Supports population growth
   - 💻 **Technology**: Unlocks the most advanced buildings

4. **Buildings**: Six types of structures to construct:
   - 🌱 **Land Formation**: Generates Land resources
   - 🏘️ **Settlement**: Provides Energy generation
   - 🌾 **Farm**: Increases Light, Water, and Food generation
   - ⛏️ **Metal Mine**: Produces Metal resources
   - 🔬 **Technology Lab**: Generates Technology points
   - 🌀 **Dimensional Gate**: The ultimate structure (requires all other achievements)

5. **Achievements**: Unlock 9 achievements that provide beneficial buffs:
   - Complete specific milestones to earn temporary resource bonuses
   - Achieve "Victory" by unlocking all achievements and building the Dimensional Gate

## Game Mechanics Ported from Python

### Core Systems
- **Player Progression**: Experience points and leveling system
- **Resource Management**: Seven-resource economy with manual gathering and automatic generation
- **Building System**: Construction costs, building effects, and upgrade mechanics
- **Population Dynamics**: Growth mechanics with capacity limits
- **Achievement System**: Goal-based progression with reward buffs
- **Random Events**: Chance-based events that affect resources and population

### Turn-Based Gameplay
- Each action or "Next Turn" advances the game state
- Automatic resource generation based on population and buildings
- Population growth over time
- Random events with various effects
- Achievement checking and buff application

### Key Differences from Python Version
- **Interface**: Modern web UI instead of command-line interface
- **Interaction**: Click-based actions instead of text menu selection
- **Visual Feedback**: Real-time resource updates and visual progress indicators
- **Streamlined**: Removed some placeholder features (missions) to focus on core gameplay

## Technical Architecture

### Files Structure
- `index.html`: Main game interface with resource displays, action buttons, and modals
- `style.css`: Modern CSS styling with responsive design and animations
- `game.js`: Complete game logic ported from Python classes to JavaScript

### JavaScript Classes (Ported from Python)
- **Player**: Manages player name, level, and experience
- **ResourceManager**: Handles all resource operations (gathering, spending, automatic generation)
- **Population**: Manages population growth and capacity upgrades
- **BuildingManager**: Handles building construction, upgrades, and effects
- **AchievementManager**: Tracks progress and applies achievement buffs
- **EventManager**: Triggers random events each turn
- **Game**: Main game controller that coordinates all systems

### Key Features
- **Responsive Design**: Works on desktop and mobile devices
- **Real-time Updates**: All displays update immediately when values change
- **Modal System**: Clean interfaces for building selection and upgrades
- **Game Log**: Running history of all actions and events
- **Visual Polish**: Smooth animations and modern UI elements

## Extending the Game

### Adding New Buildings
1. Add to `BuildingManager.getAvailableBuildings()` array
2. Add emoji to `buildingEmojis` object
3. Define effects in `getBuildingEffects()`
4. Add upgrade costs in `getUpgradeCost()` if needed

### Adding New Achievements
1. Add to `AchievementManager.achievements` object
2. Define unlock condition
3. Specify reward type and parameters
4. Add check calls in appropriate game methods

### Adding New Events
1. Add event object to `EventManager.events` array
2. Define name, description, effect function, and chance
3. Event will automatically be included in random event checks

### Adding New Resources
1. Add to `ResourceManager.resources` and `symbols` objects
2. Update HTML to include new resource display
3. Update CSS for new resource styling
4. Add resource to relevant building costs and effects
